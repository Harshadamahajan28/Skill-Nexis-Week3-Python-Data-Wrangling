# Skill Nexis Week 3 - Python & Data Wrangling

## Topics covered
- Python basics and scripting
- Pandas data loading, filtering, cleaning, grouping and merging
- Missing-value handling
- New calculated columns
- Matplotlib visualization
- Seaborn visualization

## Dataset
The project uses the Global Superstore sales dataset already used in the Skill Nexis Week 1 project workbook because the Week 3 Google Drive assignment link supplied in the chat was not accessible.

## Main files
- Week3_Python_Data_Wrangling_Executed.ipynb - notebook with code and executed outputs
- Week3_Python_Data_Wrangling.py - Python script
- Skill_Nexis_Week1_Sales_Performance_Project.xlsx - source workbook used by the notebook
- cleaned_sales_data.csv - cleaned dataset
- sales_by_category.csv - category summary
- sales_by_year.csv - yearly summary
- top_10_customers.csv - top customer summary
- sales_by_category.png - Matplotlib chart
- yearly_sales_trend.png - Matplotlib chart

## Key cleaning steps
- Checked duplicate rows
- Converted dates and numeric columns
- Handled missing Postal Code values by using 0 as a missing-code marker
- Created Year, Sales_Per_Unit, Profit_Margin_% and Sales_Level columns
